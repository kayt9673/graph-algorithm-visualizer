# graph-algorithm-visualizer

A tool to help me better visualize some of the graph algorithms I'm learning! :D

### Notes
- The entire project is written fully in TypeScript. To launch it, simply run `npm run dev` in your terminal.
- For specific algorithm details, I typically reference [this textbook](https://www.amazon.com/Algorithm-Design-Jon-Kleinberg/dp/0321295358) when necessary.
